## 🎯 Tech Stack & Core Domains

We regularly design and build real-world applications using the following modern tech stack:

- **AI Frameworks & Orchestration:** LangChain, LangGraph, LlamaIndex, Autonomous Agents
- **Vector Search & RAG:** PGVector, Hybrid Search, Hybrid RAG Architecture, Vector DBs
- **Backend Architecture:** FastAPI (Python 3.13+), Async Workflows, Celery, Redis
- **Database & Storage:** PostgreSQL 18, Vector Search Optimization, Database Indexing
- **Mobile & Web Frontend:** Flutter (Cross-platform Apps), Next.js, Tailwind CSS
- **DevOps & Infrastructure:** Docker, Containerization, Microservices, CI/CD Pipelines
